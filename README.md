# Relationship Anarchy Smorgasbord

An interactive web tool for exploring and communicating about different elements of relationships, based on the Relationship Anarchy Smorgasbord concept.

## About

The Relationship Anarchy Smorgasbord is a tool designed to help people think about and communicate their desires, boundaries, and preferences in relationships. Unlike traditional relationship models that follow preset scripts, relationship anarchy encourages creating custom relationship agreements that work for everyone involved.

This interactive tool allows you to:
- Explore different categories of relationship elements
- Select your level of interest or comfort with each element
- Save your selections for personal reference
- Export your results to share with partners or for discussion

## Usage

Simply open `index.html` in your web browser to start using the tool.

### How to Use

1. **Browse Categories**: The tool is organized into different categories like Romantic, Emotional Intimacy, Physical Intimacy, etc.

2. **Select Elements**: Click on any element to cycle through states:
   - Green = Want / Interested
   - Yellow = Maybe / Open to Discussion
   - Red = Not Interested / No
   - Gray = Unselected

3. **Save Automatically**: Your selections are automatically saved to your browser's local storage.

4. **Export Results**: Click the "Export Results" button to download your selections as both JSON and text files that you can share or reference later.

5. **Clear All**: Use the "Clear All" button to reset all selections.

This is a static web application built with vanilla HTML, CSS, and JavaScript. No build process or dependencies required.

### Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and layout
- `data.js` - Relationship elements data
- `app.js` - Application logic and interactivity
